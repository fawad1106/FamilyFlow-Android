# LifeOS product direction

LifeOS is a personal command center for tasks, projects, notes, deadlines, and files.

Core question:
> What matters right now, and where does everything related to it live?

Core objects:
- Task
- Project
- Note
- Deadline
- File
- Tag

Build order:
1. Tasks
2. Database
3. Projects
4. Relationships
5. Notes
6. Deadlines
7. Dashboard
8. Search
9. Authentication
10. Public deployment
